# 💻 DKFolio — Dynamic macOS-Style Portfolio Website

DKFolio is my **personal portfolio website**, designed with a **macOS-inspired interface and animated dock-style navigation**.  
The goal was to create a portfolio experience that feels **modern, dynamic, smooth, and different from traditional scrolling résumé sites**.

---

## 🌟 Highlights

- 🖥 macOS-themed user interface
- 🪄 Interactive **dock-style app launcher navigation**
- ⚡ Fully **dynamic page transitions**
- 🎨 Smooth animations and minimal UI design
- 🌑 **Dark-toned / mac-theme aesthetic**
- 💼 Showcases **projects, skills, achievements, and contact info**
- 📱 Responsive across devices

---

## 🎯 Purpose

DKFolio was built to represent **who I am as a developer and roboticist**, in a way that reflects:

- creativity  
- interactivity  
- technical detail  
- and clean visual taste  

Rather than a static résumé page, DKFolio feels like **a personal operating system** built for exploration.
